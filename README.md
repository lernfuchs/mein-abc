# Mein ABC – Buchstaben und Bilder

Ein kleines Lernspiel für Kinder: Buchstaben-Klötze den passenden Bildern zuordnen, Punkte und Pokale sammeln.

Alles steckt in einer einzigen Datei (`index.html`) – keine Installation, kein Build.

## Starten

- **Lokal:** `index.html` im Browser öffnen.
- **GitHub Pages:** Repository → *Settings* → *Pages* → Branch `main`, Ordner `/ (root)` → speichern. Das Spiel ist dann unter https://lernfuchs.github.io/mein-abc/ erreichbar.

Der Spielstand wird im Browser (localStorage) gespeichert.

## Vorschaubild (WhatsApp & Co.)

`preview.png` ist das Vorschaubild für geteilte Links (WhatsApp, Telegram, Signal usw.). Die Adressen in `index.html` zeigen auf https://lernfuchs.github.io/mein-abc/.
